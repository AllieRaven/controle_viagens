# controle_viagens
Sistema de Controle de Viagens e Diárias Oficiais

Aplicação desenvolvida para gerenciar viagens oficiais de servidores públicos e o controle de diárias. O sistema permite cadastrar servidores (CPF, nome e telefone) e registrar viagens contendo informações como período e valor das diárias. Entre as funcionalidades disponíveis estão: adicionar e remover viagens, consultar viagens por CPF do servidor com cálculo do total de diárias recebidas e listar todas as viagens ordenadas por data. O objetivo é facilitar o acompanhamento e a administração das despesas relacionadas a deslocamentos oficiais.
